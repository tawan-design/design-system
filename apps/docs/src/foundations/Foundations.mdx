# Foundations

Every value on this page is **generated from `packages/tokens/src`**, which is exported from the
Figma file **TAWAN DESIGN SYSTEM** (Variables). Names match Figma exactly:

| Figma variable | CSS variable | Tailwind class |
|---|---|---|
| `content-secondary` | `var(--content-secondary)` | `text-content-secondary` |
| `surface-primary` | `var(--surface-primary)` | `bg-surface-primary` |
| `border-strong` | `var(--border-strong)` | `border-border-strong` |
| `space-16` | `var(--space-16)` | `p-16`, `gap-16` |
| `radius-md` | `var(--radius-md)` | `rounded-md` |
| `body-md-*` | `var(--body-md-font-size)` … | `text-body-md` |

> Components may only use **semantic** tokens (`content-*`, `surface-*`, `border-*`, `icon-*`, `action-*`),
> never primitives (`color primitives/brand/50`) or raw values. Switch **Theme** in the toolbar to preview the page in Dark mode.

Defaults built today: **Light/Dark**, **Brand 1**, **Balanced** radius, **Font1**. Brand 2, Sharp/Rounded radius and
Font2 are stored in `packages/tokens/src/modes/` for a later theme.
