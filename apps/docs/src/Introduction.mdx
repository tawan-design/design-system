# Design System

Owned by the **Design team**. Built with React + TypeScript, Radix (behavior) and Tailwind (styling via tokens).

| Section | What you'll find |
|---|---|
| **Foundations** | Color, spacing, radius, type, generated from Figma Variables |
| **Components** | Every component with live controls, states, a11y checks and its Figma frame |
| **Pages** | Real product flows built *only* from the system, the "simulated product" |

## Use it in a product

```bash
pnpm add @tawan-design/ui
```

```tsx
import "@tawan-design/ui/styles.css";
import { Button } from "@tawan-design/ui";
```
